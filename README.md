# GymFit Pro

GymFit Pro es mi proyecto final del ciclo de Desarrollo de Aplicaciones Web. La idea es una web para un gimnasio donde los socios puedan ver las clases dirigidas (zumba, spinning, pilates, etc.) y reservar su plaza online, sin tener que apuntarse a mano en recepción. La web controla el aforo de cada clase para que nunca se apunte más gente de la que cabe.

Habrá dos tipos de usuario. El socio, que puede ver las actividades, reservar y cancelar sus reservas, y el administrador, que gestiona las actividades, los ejercicios y los usuarios desde su propio panel.

## Estado del proyecto

Ahora mismo el proyecto está en la fase de diseño. Ya he entregado la propuesta inicial y el prototipo de la página principal, y a partir de aquí iré subiendo poco a poco la parte de programación.

En la carpeta `docs/entregas` están los documentos de las entregas que llevo hechas hasta ahora.

## Tecnologías que voy a usar

PHP con PDO y MySQL para la parte del servidor, HTML5 y CSS hecho a mano para la parte visual, y JavaScript con jQuery para la parte del cliente. En local trabajo con XAMPP.
